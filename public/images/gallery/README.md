Drop your gallery photos in this folder using these exact filenames
(matched by `src/components/Gallery.jsx`):

- engagement.jpg
- together.jpg
- celebration.jpg
- mehendi.jpg
- ring-ceremony.jpg
- family.jpg
- love.jpg
- happy-moments.jpg

Any image format works (.jpg, .png, .webp) — just update the matching
`src` path in `src/components/Gallery.jsx` if you use a different
extension. Until a file exists, that slide falls back to its colored
placeholder background.
